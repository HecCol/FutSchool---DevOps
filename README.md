# FutSchool - DevOps

Repositorio utilizado para el desarrollo y gestión del proyecto FutSchool.

FutSchool es una aplicación móvil enfocada en la gestión y organización de torneos de fútbol escolares.

## Organización del repositorio

- `app/`: código fuente del proyecto.
- `docs/`: documentación del proyecto.
- `.github/`: configuración de GitHub Actions y plantillas del repositorio.

## Flujo de trabajo

Se utilizará una estrategia basada en GitHub Flow.

- `main`: rama principal y estable.
- `feature/*`: desarrollo de nuevas funcionalidades.
- `hotfix/*`: corrección de errores importantes.
- Los cambios se integrarán mediante Pull Request.

## DevOps

El proyecto contempla integración continua mediante GitHub Actions, pruebas progresivas durante el desarrollo y seguimiento de actividades mediante GitHub Projects.

## Comunicación

La comunicación del equipo se realizará utilizando la herramienta seleccionada en la Matriz y Dictamen de Comunicación.

## Documentación

Los documentos relacionados con la planeación y gestión del proyecto se encuentran dentro de la carpeta `docs/`.
